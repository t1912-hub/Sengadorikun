Apple Pencil や スタイラスの筆圧に対応しています。
紙は画面いっぱいには広げません。拡大して細部を作り込むより、 ラフを手早く重ねることを優先しているためです。
ペンを使うと、手のひらが触れても描きません。

コマを長押しすると長さや削除を選べます。

enter 新しいコマ（n も可）
0 再生 / 8 ループ再生の切替
4 6 コマ送り（← → も可）
del 見ているコマを削除 / ⌘Z 取り消す

ホーム画面に追加すると全画面で使えます。
描いたものは端末に残るので、閉じても続けられます。
