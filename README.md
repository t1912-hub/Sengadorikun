# 線画撮りくん / ラフガキちゃん

動画用紙に鉛筆で描く作画を支えるための、教育用アニメーション制作アプリ。
東京工芸大学での授業・演習で使うために作っています。

**ブラウザ版はこちらから、インストールせずに使えます。**

- 線画撮りくん https://t1912-hub.github.io/Sengadorikun/
- ラフガキちゃん https://t1912-hub.github.io/Sengadorikun/rough/

---

## 作っているもの

| | 何をするもの | 動く場所 |
|---|---|---|
| **線画撮りくん** | 動画用紙に描いた線をカメラで1コマずつ撮り、重ねて見ながらパラパラ再生する | macOS / iPad / iPhone / ブラウザ |
| **ラフガキちゃん** | Apple Pencil でラフを描く。前後のコマを透かしながら動きを作る | iPad / ブラウザ |

どちらも、紙に描く手の動きを止めないことだけを考えて作っています。
機能を増やすより、起動して紙を置いてシャッターを押すまでの最短経路を保つことを優先しています。

## 考えていること

人工知能に絵を描かせるのではなく、**人が描くための道具を作る**ために使う、という立場で進めています。
塗ったり描いたりすること自体が人間にとっての楽しみであって、
そこへ早く、長く、深く浸かるための環境づくりに機械の力を使いたい。
出力先は作品ではなく道具である、という考え方です。

このリポジトリは、その実例として公開しています。

## ブラウザ版の使い方

1. 上のURLを開く
2. カメラの使用を許可する
3. 「鉛筆線の2値化」を**有効**にする（**おまかせ**のままで構いません）
4. 動画用紙を撮る

**ホーム画面に追加すると全画面になります。**
iPad / iPhone の Safari なら共有ボタン → 「ホーム画面に追加」、
Android の Chrome ならメニュー → 「アプリをインストール」。
ブラウザのバーが消えて、撮影に使える面積が広がります。

撮ったコマは端末の中に残るので、閉じても続けられます。

### 鉛筆線の2値化について

薄い鉛筆線を黒く、紙を白く分けて見やすくする処理です。
既定の「おまかせ」は Sauvola の局所しきい値を使っています。

```
T = 局所平均 × (1 + k × (局所標準偏差 / 128 − 1))
```

平らな所（紙や影）は標準偏差が小さいのでしきい値が下がって白のまま残り、
線のある所は標準偏差が大きいのでしきい値が上がって拾われます。
机に落ちた影を黒く塗り潰さずに線だけを出せるのが、この方式を選んだ理由です。

影の傾きを付けた動画用紙を合成して測ったところ、紙を誤って黒くした割合は次の通りでした。

| 方式 | 線を拾えた | 紙を誤って黒くした |
|---|---|---|
| おまかせ（Sauvola） | 100% | **0.2%** |
| 適応（局所平均との比較） | 100% | 42.3% |
| 単純（一定のしきい値） | 88% | 31.8% |

線が薄くて拾えないときは「拾う強さ」を右へ動かします。

### 動く環境

iPad / iPhone の Safari、Android の Chrome、Chromebook、Windows / Mac のブラウザ。
カメラを使うため、`https://` で開く必要があります（上のURLはそのまま使えます）。

## ネイティブ版のビルド

`PencilTest.xcodeproj` を Xcode で開き、スキームを選んでビルドします。

| スキーム | 中身 |
|---|---|
| `PencilTest-macOS` | 線画撮りくん（Mac。外付けカメラを使う） |
| `PencilTest-iOS` | 線画撮りくん（iPad / iPhone） |
| `RoughFlip` | ラフガキちゃん（iPad） |

Mac 版は Xcode を使わず `bash build.command` でもビルドできます。

テストは `bash run_tests.command`（現在153件）。

### 構成

```
Shared/     3本で共有する中身
  FrameStore.swift        コマの保持・ディスク保存・取り消し
  MP4Exporter.swift       フル解像度のPNGを1枚ずつ流してMP4にする
  SequenceExporter.swift  PNG連番フォルダとzip
macOS/      線画撮りくん（Mac）
iOS/        線画撮りくん（iPad / iPhone）
RoughFlip/  ラフガキちゃん
docs/       ブラウザ版（GitHub Pages で配っているもの）
Tests/      テスト
```

## 書き出し

動画（MP4）と PNG連番（zip）のどちらでも出せます。

PNG連番はコマの長さを展開して並べるので、2コマ打ちもそのまま入ります。
実時間で録る必要がないため尺の誤差が出ません。編集ソフトに読ませて
正確な尺で扱いたいときはこちらを使ってください。
zip の中のファイル名は英数字に揃えてあります。古い展開ツールや
編集ソフトが日本語名を読めないことがあるためです。

## まだ無いもの

- 名前を付けたプロジェクトの出し入れ（ブラウザ版は1つだけ自動保存）
- コマの並べ替え（ラフガキちゃんのブラウザ版）
- Android のネイティブ版（ブラウザ版で代替しています）

### ブラウザ版の書き出しについて

ラフガキちゃんは線を座標で持っているので、書き出しは本当に 1920x1080 で引き直されます。
線画撮りくんはカメラの絵を長辺 1024px で持つため、FHD を選んでも引き伸ばしで、
情報量は増えません。本当の FHD が要るときは iPad のネイティブ版を使ってください。
あちらはフル解像度の PNG をディスクに残し、1枚ずつ流して書き出します。

動画はブラウザの録画機能を使うため実時間でしか録れず、尺に半コマ程度の誤差が出ます。
コマの間隔は補正しているので動きの速さは保たれます。
