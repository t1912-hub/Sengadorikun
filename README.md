# 線画撮りくん — 作画チェック用コマ撮りアプリ（macOS / iPhone / iPad）

動画用紙で描いた原画をカメラで1コマずつ撮影し、オニオンスキンで前のコマを確認しながら
パラパラ再生・MP4書き出しができるMacネイティブアプリです。

---

## ビルド手順

### 1. Xcode Command Line Tools を入れる（初回のみ）

ターミナルを開いて実行します。

```
xcode-select --install
```

すでに Xcode 本体が入っていれば不要です。確認するには：

```
swiftc --version
```

バージョンが表示されればOKです。

### 2. ビルドする

このフォルダの **build.command をダブルクリック** します。
（ダブルクリックで開かない場合は、右クリック → 開く）

ターミナルが開いてコンパイルが走り、30秒ほどで同じフォルダに
**PencilTest.app** ができます。

コマンドで実行してもかまいません：

```
cd /path/to/PencilTest
bash build.command
```

### 3. 起動する

PencilTest.app をダブルクリック。
初回起動時にカメラへのアクセス許可を聞かれるので「許可」を選びます。

「開発元を検証できません」と出た場合は、
アプリを右クリック → 開く → もう一度「開く」を選んでください。

好きな場所（アプリケーションフォルダなど）に移動して構いません。

## 使い方

| 操作 | キー |
|---|---|
| 1コマ撮影 | `space` |
| 再生 / 停止 | `return` |
| 直前のコマを削除 | `delete` |
| コマ送り | `←` `→` |
| ライブビューに戻る | `esc` |

- **カメラ選択**（上部のメニュー）: 内蔵カメラのほか、USBカメラ、iPhoneの連係カメラも選べます。
  机の上に固定した iPhone を連係カメラで使うのが一番きれいに撮れます。
- **オニオンスキン**: 直前の1〜3コマを半透明で重ねて表示します。濃さと枚数を調整できます。
- **サムネイル**: クリックでそのコマを大きく表示。右クリックで削除・複製・並べ替え。
  「複製」は同じコマを2枚並べる（いわゆる2コマ打ち）確認に使えます。
- **MP4として書き出す**: H.264のMP4を保存します。QuickTime や Premiere でそのまま開けます。

---

## 撮影のコツ

- iPhone やカメラは必ず固定してください。手持ちだとコマごとに画角がずれてチラつきます。
- 部屋の照明ではなく、机の左右から均一に当たるライトを使うと影が出にくくなります。
- 蛍光灯やLEDのちらつきが出る場合は、光源を白熱灯かLEDライト（フリッカーフリー）に変えてください。

---

## 構成ファイル

- `PencilTest.swift` — アプリ本体のソースコード
- `Info.plist` — アプリの設定（カメラ利用の説明文など）
- `build.command` — ビルド用スクリプト
